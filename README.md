# Voxel What If Studio

A browser-based prototype for turning hypothetical questions into cinematic voxel story sequences.

## Included in prototype
- Interactive Three.js voxel village preview with orbit controls
- Five-beat story timeline with director notes
- Editable What If prompt
- Scene progression and preview controls
- Exportable storyboard brief (.txt)
- Responsive dark creative-workspace interface

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Current limitations
This is a visual production prototype, not a complete AI video generator. Story beats are sample content. AI script generation, automatic scene generation from prompts, audio, MP4 rendering, and full physical simulations are not implemented yet.
